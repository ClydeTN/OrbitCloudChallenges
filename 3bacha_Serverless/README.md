# Vulnerable AWS Environment for CTF Challenge

This repository contains a vulnerable AWS environment created using Terraform for a Cloud Security CTF challenge.

## Setup Instructions

1. Configure AWS credentials
2. Initialize Terraform:
   ```bash
   terraform init
   ```
3. Review the plan:
   ```bash
   terraform plan
   ```
4. Apply the configuration:
   ```bash
   terraform apply
   ```

## Security Notes

This environment is intentionally vulnerable for CTF purposes. Do not deploy this in a production environment.
